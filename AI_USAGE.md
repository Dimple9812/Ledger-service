AI Usage

**Overview**

AI tools were used as development assistants during the implementation of this Multi-Tenant Accounting Ledger project.

The purpose of using AI was to support understanding of technical concepts, explore implementation approaches, 
improve code structure, and troubleshoot development issues.

Areas Where AI Assistance Was Used

1. Project Architecture
* Discussed the layered architecture of the Spring Boot application.
* Explored separation of controllers, services, repositories, entities, and DTOs.
* Reviewed approaches for implementing tenant isolation.

2. API Development
* Used AI assistance to understand REST API implementation patterns.
* Explored validation, request handling, response structures, and exception handling.
* Reviewed approaches for journal entry creation, retrieval, reversal, and account balance calculation.

3. Database Design
* Discussed entity relationships and database constraints.
* Explored the use of PostgreSQL, JPA, and Flyway migrations.
* Reviewed approaches for maintaining data integrity and preventing duplicate entries.

4. Testing and Debugging
* Used AI assistance to understand test cases for:
    * Unbalanced journal entry rejection.
    * Idempotent journal entry creation.
    * Docker password error 
    * Tenant data isolation.
* Investigated application test failures and timezone configuration issues.

5. Documentation
* Used AI assistance to understand API behavior, design decisions, project setup, and README structure.
